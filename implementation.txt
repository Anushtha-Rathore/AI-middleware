

# Final Implementation Plan

Based on your clarification, we will use a **hybrid** architecture:
1. The **frontend** continues to send flat values (e.g. `creativity_level: 2`) but will now also explicitly send the `service` and `model` names in its update payloads.
2. The **backend** natively transforms those flat values into `{mode, value}` by checking the `modelConfigDocument` definitions before saving.
3. The **frontend** will receive standard DB documents containing `{mode, value}` on read (GET) and unpack them only for the UI display.

### 2. Node.js Backend (`ai-middleware`)

#### [MODIFY] `src/utils/agentConfig.utils.js` (NEW)
We create the dynamic transformation utility.
It iterates the incoming flat payload and targets only the advanced metrics natively defined for the model (by detecting a `min` binding in `modelConfigDocument`).
```javascript
export const transformAdvancedParams = (payloadConfig, service, modelName, modelConfigDocument) => {
  if (!payloadConfig || !service || !modelName) return payloadConfig;
  
  const serviceLower = service.toLowerCase();
  const modelDef = modelConfigDocument[serviceLower]?.[modelName]?.configuration;
  if (!modelDef) return payloadConfig;

  const transformedConfig = { ...payloadConfig };
  
  for (const key in payloadConfig) {
    // If the key exists in DB definition and has min/max properties (indicating an advanced parameter slider)
    if (modelDef[key] && modelDef[key].type && modelDef[key].type.min !== undefined) {
      const val = payloadConfig[key];
      if (val === "default") {
        transformedConfig[key] = { mode: "default", value: null };
      } else if (val === "min" || val === "max") {
        transformedConfig[key] = { mode: val, value: null };
      } else if (typeof val === "number" || typeof val === "string") {
        transformedConfig[key] = { mode: "custom", value: Number(val) };
      }
    }
  }
  return transformedConfig;
};
```

async def model_config_change(modelConfiguration, custom_config, service):
    new_custom_config = custom_config.copy()
    for key, obj in custom_config.items():
        mode, value = None, None
        
        if isinstance(obj, dict) and "mode" in obj:
             mode = obj.get("mode")
             value = obj.get("value")
        else:
             mode = obj if obj in ["default", "min", "max"] else "custom"
             value = obj if mode == "custom" else None
             
        # Run original modelConfiguration rules...
        if mode == "default":
             if not (service == "anthropic" and key == "max_tokens"):
                 del new_custom_config[key]
             else:
                 new_custom_config[key] = modelConfiguration[key].get("default")
        elif mode == "min":
             new_custom_config[key] = modelConfiguration[key].get("min")
        elif mode == "max":
             new_custom_config[key] = modelConfiguration[key].get("max")
        elif mode == "custom":
             new_custom_config[key] = value
             
    return new_custom_config
